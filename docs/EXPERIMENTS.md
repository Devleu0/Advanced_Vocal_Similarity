# EXPERIMENTS — 기대 효과와 검증 상태

각 변경이 **무엇을 겨냥하고**, **얼마나 검증됐는지**를 기록합니다.

- 검증 상태: `미검증`(코드 추론/기대치) · `합성 데이터`(가짜 임베딩으로 확인) · `측정됨`(실제 데이터에서 `evaluate.py`)
- 결과 칸은 실제 측정 후 채웁니다. **측정 전 프리셋/기본값을 바꾸지 마세요.**

## 측정 방법

```
python main.py --model <모델> [--set OPTION=값 ...]   # 임베딩 생성 (설정별로 재생성/캐시됨)
python evaluate.py --model <모델>                      # EER↓, top-1↑, intra/inter gap↑ (raw / centered)
```

- 전제: 영상이 2개 이상인 아티스트가 2명 이상. 결과 해석은 아티스트 수가 많을수록 안정적입니다.
- 평가는 영상 단위 지문 기준입니다 (`score_normalize`/`ARTIST_SCORING` 등 아티스트 단위 후처리는 평가에 반영되지 않음).

## 항목별 상태

| 변경 | 겨냥하는 문제 | 기대 효과 | 검증 상태 | 결과 |
|---|---|---|---|---|
| 꼬리 청크 패딩 (`encode_chunks`) | 길이가 다른 청크 `torch.stack` 실패 → 지문 추출 예외 | 5초 배수가 아닌 영상도 처리됨 | 미검증 (코드 추론, 단위 테스트 작성) | - |
| 청크 임베딩 L2 정규화 후 집계 | 노름이 큰 청크가 평균을 지배 | 지문 안정성 향상 | 미검증 | - |
| 센터링 (`USE_CENTERING`, 5명 이상) | 같은 장르 가수끼리 코사인이 전반적으로 높음 | 아티스트 간 대비 증가 | 합성 데이터 | 아래 참고 |
| 모델 `wavlm-sv` (추천 표시) | ECAPA-VoxCeleb 는 말소리 중심 학습 | 노래 음성에 더 강건할 것으로 **기대** | 미검증 | - |
| `MULTI_SPEAKER_FILTER` | 듀엣/코러스가 지문을 오염 | 메인 보컬 쪽 지문 | 미검증 (가정: 더 큰 군집 = 메인 보컬) | - |
| `VAD_BACKEND=silero` | RMS VAD 가 간주/숨소리를 못 거름 | 유효 발성 구간 선별 | 미검증 (노래에서 Silero 발성 비율이 낮게 나올 위험) | - |
| `VAD_RELATIVE_RATIO` | 분리 후 남는 잔향/코러스 | 조용한 구간 제거 | 미검증 | - |
| `DEMUCS_SHIFTS` | 보컬 분리 품질 | 분리 품질↑ (시간 N배) | 미검증 | - |
| `ARTIST_SCORING=video_max/topk` | 창법이 다양한 가수가 평균 하나로 뭉개짐 | 한 창법이 닮은 경우 반영 | 합성 데이터(단위 테스트) | - |
| `SCORE_NORM=snorm` | '누구와도 닮은' 허브 아티스트 과대평가 | 점수 보정 | 미검증 | - |
| `ENSEMBLE_MODELS` | 단일 모델의 약점 | 모델 간 점수 평균 | 미검증 | - |
| `CHUNK_HOP_SEC` (겹침) | 청크 수 부족 | 임베딩 수↑ | 미검증 | - |

## 기록된 측정

### 센터링 — numpy 합성 데이터 (실제 오디오 아님)
설정: 12명 × 4영상, 192차원, 공통 성분(2.0) + 개인 성분(0.6) + 영상 잡음(1.0).

| | top-1 정확도 | EER |
|---|---|---|
| raw | 0.979 | 0.058 |
| centered | 0.938 | 0.029 |

**해석 주의**: EER 은 개선됐지만 top-1 은 오히려 낮아졌습니다. 센터링의 이득은 "점수 분포의 분리(임계값 기반 판단)"이고 최근접 검색 정확도는 보장하지 않습니다. 실제 데이터에서 반드시 `evaluate.py` 로 확인해야 하며, 이전 PR 설명의 "top-1 은 비슷" 표현은 이 표로 정정합니다.
